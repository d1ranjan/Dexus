# Dexus

> **Connect your thoughts.**

Dexus is an AI-powered personal knowledge and productivity platform designed to help people capture thoughts, organise information, manage goals, and turn ideas into action.

## Product capabilities

Dexus supports private account workspaces, Brain Dump capture and structured AI extraction, tasks, goals, knowledge, people, documents, search, insights, and a protected administrative workspace. Access control, user isolation, audit logging, and controlled administrative content access are enforced on the server.

## Development

Run `pnpm dev` to start the mobile and server development environment. Use `pnpm test` for the standard test suite and `pnpm check` for type validation. Live managed-database integration checks are documented in `DATABASE_RESUMPTION.md` and `ADMIN_VERIFICATION.md`.
